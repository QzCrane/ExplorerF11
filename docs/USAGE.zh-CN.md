# 使用说明

面向使用者的完整说明。技术细节在 [ARCHITECTURE.md](ARCHITECTURE.md)，足迹清单在
[FOOTPRINTS.md](FOOTPRINTS.md)。English: [USAGE.en.md](USAGE.en.md)。

## 它做什么

资源管理器每开一个新文件夹窗口，它自动给那个窗口做一次「进全屏再退出」的动作。
新标签页、从最小化还原的窗口也一样处理。做完之后，那个窗口翻目录会明显更顺。

它只投递键盘消息，不注入进程、不改系统文件、不需要管理员权限，也不改资源管理器
的任何界面（装了 ExplorerPatcher 也能一起用）。

## 它不做什么

- **不是系统修复**：微软没修这个行为，这只是把流传的手动技巧自动化。
- **不改设置项**：不会动你的「显示文件扩展名」「打开位置」之类的选项。
- **不接管资源管理器**：崩溃了不会连带它，它只是旁观 Shell 的事件。
- **不联网**：没有任何网络代码。

## 三种用法

**一、先试试。** 双击 exe，托盘出现图标。开一个新文件夹窗口，翻两下目录，对比
一下另一个没被处理的窗口。不满意就托盘 →「清除全部痕迹并退出」，删掉 exe。

**二、常驻。** 双击后就这么放着。它会一直待在托盘里，新窗口自动处理。

**三、开机自启。** 托盘 →「开机自启」打勾。写入的只有一条
`HKCU\...\Run\ExplorerF11`，内容是 exe 的完整路径（带引号、不带参数）。

exe 放哪都行，但**别放在会被清理的临时目录**，也别在勾了自启之后挪位置——挪了就
重新勾一次。

## 托盘菜单

右键托盘图标，从上到下固定五段：

```
ExplorerF11  ·  已加速 3 个窗口        ← 灰色，不可点
────────────────────────────
对所有已打开的窗口应用
对当前窗口立即应用
暂停加速
────────────────────────────
✓ 新标签页也加速
✓ 启动时处理已打开的窗口
✓ 开机自启
────────────────────────────
足迹报告（2 处）…
清除全部痕迹并退出…
────────────────────────────
退出
```

| 项 | 说明 |
|---|---|
| 状态行 | 显示「运行中 / 已加速 N 个窗口 / 已暂停」。不用点开就知道它在不在干活 |
| 对所有已打开的窗口应用 | 强制重做一遍，包括已经处理过的。换了主题、缩放过界面之后有用 |
| 对当前窗口立即应用 | 只对「你最后用的那个文件夹窗口」生效；没有文件夹窗口时变灰，不会点了没反应 |
| 暂停 / 恢复加速 | 临时停手，比如你要连续开十几个窗口时。不记住，重启后是运行状态 |
| 新标签页也加速 | 默认开。关掉可避免每次按 `+` 时整窗闪一下 |
| 启动时处理已打开的窗口 | 默认开。关掉则只处理启动之后新出现的窗口 |
| 开机自启 | 勾选状态 = 真的会启动。在任务管理器里禁用过也能从这里重新启用 |
| 足迹报告 | 打开完整清单，只读 |
| 清除全部痕迹并退出 | 先确认，再清空所有可清项，然后退出 |

**为什么「清除」不挨着「退出」**：两者之间隔一条分隔线，而且带「…」表示会先弹确认。
误点的代价是重装一遍，不值得省那 20 像素。

## 足迹报告窗口

`足迹报告（N 处）…` 打开的就是 `--status` 那份文本，结论在第一行：

```
结论：本程序写入 2 处（372 B）；Windows 自动记录 4 处（18.1 KB）。
　　　「清理全部痕迹」会删掉下面所有可删项；程序本体会保留。
```

往下是四段：**本程序写入 / Windows 自动记录 / 旧版本残留 / 程序文件**。每项四行：
谁写的、完整路径、当前内容、说明。路径都带 `HKCU\` 前缀，可以直接粘进 regedit 的
地址栏。

底部三个按钮：**复制全部 / 清理痕迹 / 关闭**。点「清理痕迹」后，清单**当场**变成
干净状态，标题也会改成「已清理」或「本来就干净」。

## 命令行

| 参数 | 作用 | 写不写 |
|---|---|---|
| 无参数 | 在托盘里运行 | 默认不写 |
| `--install` | 在托盘里运行，并设置开机自启 | 写一条 Run 值 |
| `--uninstall` | 只移除开机自启 | 删一条 Run 值 |
| `--status` | 打印足迹报告；退出码 0=干净、1=有痕迹 | 只读 |
| `--clean` / `--purge` | 清除全部可清痕迹后退出（会先关掉正在运行的实例） | 删 |
| `--menu` | 把托盘菜单按文本打印出来（测试用） | 只读 |
| `--lang zh\|en` | 本次运行的界面语言 | 只读 |
| `--log` | 写日志到 `%TEMP%\ExplorerF11.log` | 建一个文件 |
| `--no-initial` | 不处理启动前已经打开的窗口（仅本次） | 只读 |
| `--quiet` | 不弹任何对话框，适合脚本 | 只读 |
| `--help` / `-h` | 打印帮助 | 只读 |
| `--version` / `-v` | 打印版本号 | 只读 |

脚本里判断脏不脏：

```powershell
ExplorerF11.exe --status --quiet
if ($LASTEXITCODE -eq 0) { "干净" } else { "有痕迹" }
```

## 语言

三种决定方式，优先级从高到低：

1. `--lang zh` / `--lang en`（仅本次运行）；
2. 环境变量 `EXPLORERF11_LANG=zh`（适合便携版、脚本）；
3. 系统区域格式 + 界面语言。

判断顺序是先看区域格式再看界面语言，因为「英文界面 + 中国区」的机器很常见，这些
用户期望看到中文。界面语言只影响文字，不影响任何行为。

## 设置项

只有两个，默认都开：

| 设置 | 默认 | 存哪 |
|---|---|---|
| 新标签页也加速 | 开 | `HKCU\Software\ExplorerF11\Tabs`（只在关闭时存在） |
| 启动时处理已打开的窗口 | 开 | 同上 `InitialSweep` |

**默认值不写注册表**：改回默认会立即删掉那个值，键空了连键一起删。所以
「恢复默认」和「从未安装」在注册表里完全一样。

## 常见问题

**窗口开了但没变快？**
先看托盘状态行是不是「已暂停」。然后用「对所有已打开的窗口应用」手动重做一遍——这
能区分「没触发」和「触发了但没用」。如果重做也没用，说明这个 Windows 版本的行为
变了，`--log` 里会有 `accelerated:` 行，可以据此判断是没投递出去还是投递了没效果。

**新标签页没吃到？**
检查「新标签页也加速」是否还勾着。如果勾着却不动，多半是这个窗口在启动时被跳过了
（比如工具启动前就开着，又关掉了启动清扫），手动应用一次即可。

**按 `+` 时整窗闪一下？**
那是全屏切换的正常代价。受不了就关掉「新标签页也加速」——顶层的窗口仍然是加速过的
状态，只是新标签页不重做。

**装了 ExplorerPatcher / StartAllBack 冲突吗？**
不冲突。它只发消息，不碰界面。实测环境就装着 ExplorerPatcher。

**重启资源管理器之后失效？**
不应该。它监听 `TaskbarCreated` 广播，会重新注册钩子并重建托盘图标；万一失败会
自己重启（复用原命令行，参数不丢）。

**多显示器 / 高 DPI？**
全屏切换只在目标窗口所在的那个显示器上发生，不会把别的窗口挤走。界面按系统 DPI
缩放。

**卸载要几步？**
两步：`ExplorerF11.exe --clean`，然后删掉 exe。`--clean` 会先关掉正在运行的实例，
再清掉设置、自启、日志、旧版本残留，以及 Windows 自己为它建的记录（托盘图标缓存、
启动开关、兼容性助手、MuiCache、UserAssist，有权限时还包括 Prefetch）。

**为什么 `--clean` 之后 Prefetch 还在？**
Prefetch 目录只有管理员能读写。不带提权运行时它删不掉，报告里也不会假装删掉了。

**会把我的注册表搞乱吗？**
它只碰 [FOOTPRINTS.md](FOOTPRINTS.md) 里列出的 14 个位置，别处从不读写。不确定
的时候跑 `--status`，那就是它自己交代的账。
