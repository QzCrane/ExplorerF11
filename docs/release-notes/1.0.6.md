ExplorerF11 1.0.6 is a single-file Windows 11 utility that sends F11 to
Explorer windows so they go full screen. No installer, no runtime, no polling.

## What changed

Closing one tab in an Explorer window left the tray tooltip showing the old tab
count, while the menu — rebuilt on every open — already showed the new one. The
two surfaces disagreed until an unrelated event pushed the tooltip again. This
release makes the count follow the tab close immediately.

A tab is a `ShellTabWindowClass` child of the frame window. Closing one that is
not the last leaves the frame alive, so Windows sends no
`HSHELL_WINDOWDESTROYED`; the existing WinEvent hook only watched
`EVENT_OBJECT_CREATE` (new tabs), so nothing asked for a state rebuild. The hook
now also watches `EVENT_OBJECT_DESTROY` and reuses the 60 ms one-shot timer
already used for closed windows, collapsing a burst of closes into one recount.
By delivery time `GetClassNameW` returns 0 and `GetParent` is NULL — measured —
so the branch deliberately has no class or parent filter; the memoised tray push
skips the cross-process call when the surface did not change. A redundant
recount costs about 260 µs; the `NIM_MODIFY` it avoids costs 1.2–1.7 ms.

`test_smoke.py` now builds a marked window with two tab children, closes one,
and reads the tab count from the report the program draws — the same snapshot
the tooltip uses. The assertion fails against the previous binary (4 where 3
was expected) and passes against this one. Assertions went from 356 to 360;
gates stay at 14. Nothing else about the program changed.

## Residue

`--clean` removes only this program's own records. Anything Explorer left behind
on its own is reported, not touched. See `docs/RESIDUE.md`.
